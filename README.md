# Светомузыка на Arduino и WS2812b

Цветомузыка на Arduino и адресной светодиодной ленте: 9 режимов от звука и подсветки,
управление кнопкой, командами по USB / Bluetooth и с веб-страницы.

Исходный автор проекта — **AlexGyver** ([оригинальный репозиторий](https://github.com/AlexGyver/ColorMusic)).
Версия 3.0 — переработка его прошивки: режимы разнесены по модулям, ИК пульт заменён управлением
по Serial, добавлены веб-страница и сборка через PlatformIO.

## Режимы

| № | Режим | Что делает |
|---|---|---|
| 1 | Громкость: градиент | шкала громкости от центра, от зелёного к красному |
| 2 | Громкость: радуга | шкала громкости с бегущей радугой |
| 3 | Цветомузыка: 5 полос | низкие / средние / высокие частоты, симметрично |
| 4 | Цветомузыка: 3 полосы | то же, три полосы |
| 5 | Вспышки | вспышки всей лентой; все частоты или только низкие / средние / высокие |
| 6 | Огонь | живое пламя на шуме Перлина, цвет, скорость и масштаб настраиваются |
| 7 | Подсветка | постоянный цвет, плавная смена цвета или бегущая радуга |
| 8 | Бегущие частоты | вспышки бегут от центра к краям |
| 9 | Анализатор спектра | спектр симметрично от краёв к центру |

## Что понадобится

- Arduino Nano, Uno, Mega или Pro Micro
- адресная лента WS2812b и блок питания 5 В (примерно 3 А на каждые 100 светодиодов)
- аудиовход (гнездо 3.5 мм) или модуль микрофона, кнопка, резисторы и конденсатор — по схеме
- по желанию: Bluetooth-модуль HC-05 / HC-06 для управления без провода

## Подключение

| Что | Nano / Uno / Mega | Pro Micro |
|---|---|---|
| Вход DI ленты | D12 | D9 |
| Кнопка (пин — кнопка — GND) | D3 | D3 |
| Светодиод режимов (горит при калибровке) | D13 | D17 |
| Аудио, правый канал | A2 | A2 |
| Аудио, левый канал (если `MONO 0`) | A1 | A1 |
| Аудио для частотных режимов (через конденсатор) | A3 | A3 |
| Земля делителя опорного напряжения (если `POTENT 1`) | A0 | A0 |
| Serial для команд: RX / TX | D0 / D1 | только USB |

Bluetooth-модуль подключается к D0 / D1 (TX модуля → RX платы); на время прошивки его нужно отключать.

## Прошивка

Все настройки (количество светодиодов, пины, значения по умолчанию) — в начале файла
[`firmware/colorMusic_v3.0/colorMusic_v3.0.ino`](firmware/colorMusic_v3.0/colorMusic_v3.0.ino).

**PlatformIO:**

```bash
pio run -e nano -t upload    # платы: nano, nano_old (старый загрузчик), uno, mega, promicro
```

**Arduino IDE:** скопировать библиотеки из папки [libraries](libraries) в папку библиотек IDE,
открыть `colorMusic_v3.0.ino`, выбрать плату и порт, загрузить.

При первом запуске настройки в EEPROM сбрасываются на значения по умолчанию.

## Управление

### Кнопка

- одно нажатие — следующий режим
- удержание — калибровка шума

### Веб-страница

Страница [`web/index.html`](web/index.html) публикуется на GitHub Pages: https://webring.github.io/ColorMusic/.
Источник подключения выбирается на странице:

- **USB** — плата подключена к компьютеру с браузером. Нужны Chrome, Edge или Opera и HTTPS
  (GitHub Pages подходит).
- **Сервер** — плата подключена к другому компьютеру, на нём запускается мост (см. ниже).
- **Демо** — виртуальная плата, чтобы посмотреть интерфейс.

### Мост для управления по сети

Если плата подключена к одному компьютеру, а управлять хочется с другого или с телефона:

```bash
python3 web/server.py --serial /dev/ttyACM0 --http 8000 --https 8443
```

Страница будет доступна по адресу `http://<адрес компьютера>:8000` в любом браузере. HTTPS-порт нужен,
только чтобы с этой же страницы работал и режим USB; сертификат самоподписанный и создаётся сам.
Зависимостей нет. Пароля тоже нет: управлять сможет любой в локальной сети.

### Команды по Serial

9600 бод, пакет из 5 байт: `A5 <команда> <параметр> <значение: младший байт> <старший байт>`.

| Команда | Действие |
|---|---|
| `01` | установить параметр |
| `02` | прибавить к параметру (значение может быть отрицательным) |
| `03` | прочитать параметр, `FF` — все |
| `04` | передать текущему режиму произвольное событие |
| `05` / `06` / `07` | сохранить в EEPROM / сбросить настройки / калибровка шума |

На каждое изменение параметра (в том числе с кнопки) плата отвечает `A5 80 <параметр> <значение>`.
Например, `A5 01 00 03 00` — включить режим 4 (нумерация с 0), `A5 01 02 64 00` — яркость 100.

### Параметры

Дробные значения передаются в фиксированной точке: «×100» — сотые, «×10» — десятые.

| № | Параметр | Диапазон |
|---|---|---|
| 0 | режим | 0…8 |
| 1 | питание | 0 / 1 |
| 2 | яркость | 0…255 |
| 3 | яркость фона («не горящих» светодиодов) | 0…255 |
| 4 | порог шума, громкость | 0…1023 |
| 5 | порог шума, частоты | 0…255 |
| 6 | плавность шкалы громкости, ×100 | 5…100 |
| 7 | скорость радуги шкалы, ×10 | 5…200 |
| 8 | плавность цветомузыки, ×100 | 5…100 |
| 9 | порог вспышки (меньше — чувствительнее), ×10 | 0…100 |
| 10 | частоты для вспышек и бегущих частот: все / высокие / средние / низкие | 0…3 |
| 11 | цвет огня: 0 красный, 80 зелёный, 140 молния, 190 розовый | 0…255 |
| 12 | скорость пламени | 1…100 |
| 13 | подрежим подсветки: цвет / смена цвета / радуга | 0…2 |
| 14 | цвет подсветки | 0…255 |
| 15 | насыщенность подсветки | 0…255 |
| 16 | период смены цвета, мс | 0…255 |
| 17 | скорость и направление радуги подсветки | −20…20 |
| 18 | шаг радуги подсветки, ×10 | 5…100 |
| 19 | период сдвига бегущих частот, мс | 1…255 |
| 20 | начальный цвет спектра | 0…255 |
| 21 | шаг цвета спектра | 1…255 |
| 22 | масштаб пламени (меньше — крупнее языки) | 1…100 |

## Калибровка шума

Порог шума отсекает фон, чтобы лента не мигала в тишине. Подключите источник звука, поставьте музыку
на паузу и удерживайте кнопку около секунды (или нажмите «Калибровка шума» на странице). Значения
сохранятся в память. Если включить `AUTO_LOW_PASS`, калибровка будет выполняться при каждом запуске —
тогда в момент подачи питания музыка тоже должна стоять на паузе.

## Структура

```
firmware/colorMusic_v3.0/   прошивка
  colorMusic_v3.0.ino       настройки, список режимов, таблица параметров
  Params.h                  номера параметров
  Control.h                 команды, EEPROM, калибровка
  Audio.h                   анализ звука
  Modes*.h                  режимы
libraries/                  библиотеки (FastLED, FHT, GyverButton)
web/                        веб-страница и мост server.py
schemes/                    схемы подключения
```

Чтобы добавить режим: написать в `Modes*.h` namespace с функцией `update()` и добавить строку
в `modeList[]`. Новые параметры добавляются в конец `Params.h` и таблицы `paramMeta[]`;
список параметров продублирован в `web/index.html`.
